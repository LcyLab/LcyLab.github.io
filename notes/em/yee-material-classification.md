# 从 Yee 网格到材料分类的基本数据流

电磁仿真中的几何信息，最终要落到离散网格和材料参数上。这个过程至少包含几种不同语义：几何体是否穿过单元、单元属于哪种材料，以及求解器如何使用这些状态。

## 不要把几种状态混成一个字段

建议分别保留：

- 几何分类：`CUT`、`INSIDE`、`OUTSIDE`。
- 几何归属：单元关联的 `geometryId`。
- 材料或占据状态：空气、导体、介质等。
- 求解器状态：边界、方向标记和更新策略。

这样做的好处是，后处理或可视化需要改变时，不会反过来污染几何分类逻辑。

## 一条可追踪的数据链

```text
CAD 几何
  → 几何包围盒筛选
  → 三角形与网格单元精确判定
  → 几何分类与 geometryId
  → 材料映射
  → FDTD 求解器状态
```

每一步都应该能够单独输出中间结果，便于定位“几何错了”还是“材料映射错了”。
