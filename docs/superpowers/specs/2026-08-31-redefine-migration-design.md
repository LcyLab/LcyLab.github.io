# LCY Lab 迁移至 Redefine 主题设计

## 目标

将 `E:\LcyLabHexo` 当前的 Hexo + Matery 站点迁移为 Redefine 主题，获得更简洁、现代、适合技术笔记阅读的视觉风格，同时保留已有文章、分类、标签、图片、公式、搜索、访客统计和 GitHub Pages 部署能力。

## 不做什么

- 不更换站点域名 `https://lcylab.github.io/`；
- 不改写现有 Markdown 文章正文；
- 不加入登录、数据库、后台编辑或多用户功能；
- 不保留 Matery 的首页模板、页脚模板和统计兼容代码；
- 未经用户确认，不直接推送 GitHub 或覆盖线上页面。

## 方案

采用本地并行预览后切换的方式：

1. 安装 Redefine 主题依赖，并创建站点级 `_config.redefine.yml`；
2. 先保留 Matery 文件和覆盖目录作为回退依据；
3. 将根配置切换为 `theme: redefine`；
4. 迁移站点名称、简介、导航、首页 Banner、Logo、分类、标签、搜索、公式和真实访客统计配置；
5. 适配现有文章图片目录，使 Typora 的相对路径和生成页面中的图片路径都有效；
6. 在本地构建和浏览器中检查页面，再由用户确认是否发布。

## 页面与功能设计

### 站点信息

- 标题：`LCY Lab`；
- 副标题：电磁仿真、计算几何、C++、Qt 与 OpenCascade 学习记录；
- GitHub 链接：`https://github.com/LcyLab`；
- 关闭主题作者默认信息、打赏、评论和不属于用户的个人资料。

### 导航

保留以下入口：

- 首页；
- 学习笔记；
- 分类；
- 标签；
- 归档；
- 项目记录；
- GitHub。

### 内容

- `source/_posts/` 中的正式文章继续由 Hexo 生成；
- `source/_drafts/` 中的第一篇计算几何文章继续作为草稿；
- 分类和标签页面改为 Redefine 对应的页面模板；
- 文章页保留目录、代码高亮、数学公式、图片和文章元信息；
- 现有图片不使用外部远程地址，继续使用站点本地资源。

### 统计与搜索

- 保留真实站点 PV/UV 统计，不显示本地伪数据；
- 本地预览时统计区域显示为不可用或不请求统计服务；
- 保留 `hexo-generator-searchdb` 生成的本地搜索索引；
- Redefine 自带功能与现有统计实现冲突时，以不产生异常数字为优先。

## 构建与部署

- GitHub Actions 改为安装并构建 Redefine，不再克隆和覆盖 Matery；
- 主题配置集中放在站点根目录的 Redefine 配置文件中，避免直接修改依赖包源码；
- 保留现有 Pages 权限、构建分支和部署步骤；
- 先只做本地切换，线上同步作为单独步骤。

## 验证标准

### 内容验证

- 首页、文章、分类、标签、归档、学习笔记和项目记录页面均能生成；
- 现有文章数量不减少；
- 文章分类和标签链接可访问；
- 第一篇计算几何草稿的公式和 5 张图片可显示。

### 视觉验证

- 首页和文章页使用 Redefine 样式；
- 导航、Banner、Logo 和深浅色模式无明显错位；
- 文章目录、代码块、公式和图片不出现原始 Markdown 或破图；
- 移动端页面能够正常阅读。

### 工程验证

- `pnpm exec hexo clean` 成功；
- `pnpm exec hexo generate --draft` 成功；
- `pnpm run build` 成功；
- 站点检查脚本按 Redefine 页面结构更新后通过；
- 用户确认本地效果后，才执行 GitHub 同步和线上 Actions 验证。

## 回退策略

在用户确认 Redefine 之前，不删除 Matery 主题目录和 `theme-overrides/matery/`。如果 Redefine 预览效果或功能不符合预期，只需将根配置的 `theme` 恢复为 `matery`，即可回到当前主题。
