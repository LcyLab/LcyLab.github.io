# LCY Lab 网站基础功能设计

## 目标

让 LCY Lab 具备一个知识型个人站点的基础使用闭环：访客可以看到站点规模和访问数据，可以通过导航、搜索、分类、标签和归档浏览内容，阅读文章时可以获得目录、字数、阅读时长和浏览量等辅助信息。

## 范围

本阶段包含：

- Matery 内置的不蒜子站点 PV/UV 和文章 PV 统计；
- 文章发布日期、更新时间、字数、阅读时长；
- 首页站点概览小部件；
- 学习笔记菜单入口；
- 首页推荐文章的可见内容；
- 搜索、目录、代码复制、夜间模式、返回顶部和归档日历的构建验证；
- 关闭 Matery 的腾讯验证码占位脚本。

本阶段不包含：

- 图标和头像替换；
- 评论系统、用户登录或管理后台；
- Umami/Google Analytics 等独立统计后台；
- 个人资料、打赏、RSS 和默认社交信息恢复；
- 重新设计主题视觉风格。

## 技术方案

继续使用 Hexo 8 + Matery。统计直接打开主题已经提供的 `busuanziStatistics`，因此不新增 npm 依赖。首页概览通过一个主题 widget partial 输出静态站点数量和不蒜子动态统计标记；`index.ejs` 只增加该 partial 的调用。由于 GitHub Actions 会从远程重新克隆 Matery，所有正式覆盖内容都放到 `theme-overrides/matery/`，并在工作流中复制到构建主题目录；本地 `themes/matery/` 同步相同内容。

## 交互与显示

- 首页概览卡显示“文章、分类、标签、访问量”，并在访问量下显示“访客数”。统计服务未返回数据时保留加载状态，不伪造数字。
- 页脚显示站点总字数（开启后）、总访问量和总访客数。
- 文章信息显示发布日期、更新时间、字数、预计阅读时长和单篇浏览量。
- 菜单新增“学习笔记”，指向已有的 `/notes/` 页面。
- 首页推荐区域使用已有文章的 `top: true` 标记，先推荐站点搭建记录和一篇技术笔记。

## 验证

使用 `pnpm run clean; pnpm run build` 生成静态站点，然后检查：

- 关键路径的 HTML 文件存在；
- 首页包含站点概览、搜索入口和学习笔记导航；
- 文章页包含文章信息和单篇浏览量标记；
- 页脚包含站点 PV/UV 标记；
- 输出不包含腾讯验证码占位 appid、打赏图片标记和 `/about/` 页面；
- `search.xml` 生成。
