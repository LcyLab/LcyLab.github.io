这个站点用于把学习笔记放在 GitHub 仓库中，用 Markdown 长期维护，并通过 GitHub Pages 自动发布。

当前方案：

- Hexo：负责 Markdown 渲染和静态页面生成。
- Matery：负责博客首页、文章、归档、分类和标签的展示。
- GitHub Actions：负责构建和部署。
- `source/_posts/`：保存学习笔记。
